## JavaScript

1. Полупрозрачное пятно следует за указателем, не заменяя системный курсор.
2. Зрачки звезды реагируют на положение мыши.
3. Нажатие на звезду меняет её цвет.
4. Секции появляются при прокрутке через IntersectionObserver.
5. Проекты фильтруются по категориям.
6. Изображения и описания открываются в `<dialog>`, закрываются кнопкой, Escape и нажатием вне окна; фокус возвращается к карточке.
7. Email копируется через Clipboard API с сообщением об успехе или ручном способе.
8. Верхняя полоса отражает прогресс прокрутки.
9. Кнопка отключает анимации, учитывается `prefers-reduced-motion`.

Бегущая строка, покачивание звезды и эффекты наведения дополнительно используют CSS. На сенсорных устройствах нет фонового пятна курсора.

## Mobile First и доступность

Базовые стили рассчитаны на узкий экран. Расширения задаются через `min-width: 640px` и `min-width: 1000px`. На телефоне карточки расположены в один столбец; на широком экране — в два. Есть подписи изображений, видимый фокус, skip-link, семантические секции и уведомления `aria-live`. Основной контент доступен даже без JavaScript.

## Личная проверка перед сдачей

- Открыть `index.html` и проверить все фотографии.
- В инструментах разработчика проверить ширины 360, 390, 768 и 1440 px: нет горизонтальной прокрутки, текст не обрезается.
- Проверить фильтры: все — 5, веб-дизайн — 2, графика — 1, digital — 2.
- Открыть каждую карточку; закрыть кнопкой и Escape; проверить возврат фокуса.
- Проверить навигацию клавишей Tab и якорные ссылки.
- Подвигать мышь, нажать звезду, выключить анимации.
- Проверить настройку ОС «Уменьшение движения».
- Проверить копирование почты на HTTPS и ручную подсказку при открытии файла.
- Проверить `mailto:` и `tel:` в доступных приложениях.
- Открыть консоль браузера и проверить отсутствие ошибок.
